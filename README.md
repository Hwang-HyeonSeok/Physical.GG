# Physical.GG

![Physical.GG 로고](images/physical_gg_logo.png)

## 프로젝트 개요

**한국빅데이터문화플랫폼 & 국민체육진흥공단 주최 데이터 활용 아이디어 공모전**

각 국민체육센터의 체력측정 데이터를 활용하여 데이터 기반 문제 정의, 해결 방안 도출, 데이터 탐색, 전처리, 모델 설계(분류 & 군집화)를 수행하였습니다. 본 프로젝트는 개인 출전으로 전 과정을 단독으로 진행하였습니다.

## 세부 진행 내용

### 문제 정의 및 니즈 도출

1. **청년층 신체활동 저하 확인**
   - 통계청 국가지표체계 「2024 신체활동실천율」 및 문화체육관광부 「2023 국민생활체육」 자료를 통해 청년층의 신체활동이 저하되고 있음을 확인하였습니다.

2. **자기 건강 모니터링 채널 확보**
   - 스스로의 건강을 손쉽게 모니터링할 수 있는 채널을 제공함으로써 신체활동에 대한 관심 및 접근성을 증대시키고자 하였습니다.

### 아이디어: 티어 시스템 도입

- **청년층에게 익숙한 '티어'(등급) 개념 활용**
  - 게임 등에서 익숙한 '티어' 시스템을 체력 측정 항목에 적용하여 '피지컬 티어'를 도출하였습니다.

### 데이터 분석 및 모델링

1. **데이터 수집 및 전처리**
   - 국민체육진흥공단의 '체력측정 및 운동처방 종합 데이터'를 활용하였습니다.
   - 월별 데이터이지만 각 기록이 중복되지 않아 비시계열 데이터로 처리하였습니다.
   - 시각화 기반의 탐색적 데이터 분석(EDA)과 도메인 지식을 활용하여 이상치를 식별하였습니다.

2. **모델링**
   - **'피지컬 티어' 예측 모델**: Stacking 모델을 활용하였습니다.
     - 서브 모델(Sub Model)
     - 최종 모델(Final Model)
   - **'피지컬 타입' 분류 모델**: K-Means 클러스터링을 적용하였습니다.
     - 최적의 K 값 결정: k=7
     - 각 군집의 특성 분석

## 기술 스택

- **데이터 처리 및 전처리**: `pandas`를 활용하여 데이터 병합, 결측치 및 이상치 제거, 추가 열 생성을 수행하였습니다.
- **시각화 및 탐색적 데이터 분석**: `seaborn`을 사용하여 데이터 시각화 및 탐색적 분석을 진행하였습니다.
- **모델링 및 성능 평가**: `sklearn`을 활용하여 타겟 예측 모델 생성, GridSearch를 통한 하이퍼파라미터 튜닝, 성능 평가를 수행하였습니다.
- **클러스터링**: `K-Means` 알고리즘을 적용하여 Physical Type 측정 모델을 구축하였습니다.
