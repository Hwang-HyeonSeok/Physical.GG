# Physical.GG

![Physical.GG 로고](images/physical_gg_logo.png)

## 🧩 프로젝트 개요

**한국빅데이터문화플랫폼 & 국민체육진흥공단 주최 데이터 활용 아이디어 공모전**

각 국민체육센터의 체력측정 데이터를 활용하여  
- 데이터 기반 문제 정의  
- 해결 방안 도출  
- 데이터 탐색 및 전처리  
- 모델 설계 (분류 & 군집화)

**→ 개인 출전, 전 과정을 단독으로 수행**

---

## 📌 세부 진행 내용

### 🔎 문제 정의 / 니즈 도출

1. **청년층 신체활동 저하 확인**
   - 통계청 국가지표체계 「2024 신체활동실천율」
   - 문화체육관광부 「2023 국민생활체육」 자료 기반 분석
2. **자기 건강 모니터링 채널 확보**
   - 스스로의 건강을 손쉽게 모니터링할 수 있는 채널을 제공 → 신체활동 관심도 및 접근성 증대 가능

---

### 💡 아이디어: 티어 시스템 적용

- **청년층에게 익숙한 ‘티어(등급)’ 개념 활용**
- 예시: OP.GG 등에서의 등급 구조를 참고
- 체력 측정 항목 기반으로 ‘피지컬 티어’ feature 설계

---

### 📊 데이터 분석 및 모델링

#### 📥 데이터 수집 및 전처리

- **데이터 출처**: 국민체육진흥공단 ‘체력측정 및 운동처방 종합 데이터’
- **형태**: 월별 데이터지만, 사람(Record)이 중복되지 않아 **비시계열 데이터처럼 사용 가능**
- **EDA + 도메인 분석** 기반으로 **이상치 식별** 및 정제

#### 🧠 모델 설계

1. **‘피지컬 티어’ 예측 모델**
   - **Stacking 모델** 구성
     - Sub Models
     - Final Model

2. **‘피지컬 타입’ 분류 모델**
   - **K-Means 클러스터링** 적용
     - 최적 K 결정 기준: `k = 7`
     - 각 군집(클러스터)의 양상 분석

## ⚙️ 기술 스택

| 영역 | 도구 / 라이브러리 | 역할 |
|------|------------------|------|
| 데이터 처리 | `pandas` | 병합, 결측치 제거, 이상치 제거, 파생열 생성 |
| 시각화 / EDA | `seaborn` | 데이터 시각화 및 탐색 분석 |
| 예측 모델 | `sklearn` | 모델 생성, GridSearch를 통한 하이퍼파라미터 튜닝, 성능 평가 |
| 클러스터링 | `K-Means` | Physical Type 분류 모델 구성 |
